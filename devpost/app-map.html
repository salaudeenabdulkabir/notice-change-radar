1. Entry and result

index.html defines the single page. src/app.js loads the example, handles Compare, displays findings, and copies the action card.

2. The comparison

src/compare.js splits notices into sentences, pairs likely revisions, and keeps exact source text in each finding. Look for compareNotices to follow the main action.

3. Proof

tests/compare.test.mjs checks the changed bus time and raincoat, unchanged notices, a deadline, ambiguous wording, and empty input. Run npm test.

Practice to reuse

When an app makes a claim from someone else's text, keep the source beside the claim. Test the most consequential example first.
